GitHub 同步设置

配置 GitHub 访问令牌（Personal Access Token）以启用帖子跨设备同步功能。
帖子会作为 Issue 同步到数据仓库 zc071313/traderwatch-data。

• 需要 repo 权限（读写数据仓库）
• 在 github.com/settings/tokens 生成（选择 classic + repo 权限）
• 令牌仅保存在浏览器本地（localStorage），不会上传到任何服务器

提示：添加/修改商品后会自动同步；若其它设备看不到，点上方「立即同步商品到 GitHub」，再去该设备刷新页面即可。手机等未配置令牌的设备通过公开仓库直接读取，无需粘贴令牌。
